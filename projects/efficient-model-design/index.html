Efficient Model Design

Nov 6, 2026 · 1 min read
Code
projects

My work in neural architecture search focuses on training-free search, hardware-aware model design, and efficient architectures for vision and language models.

Tiny-NAS is a distributed, full-stack framework for zero-shot neural architecture search, with hardware-latency prediction for GPU and mobile deployment. Zen-NAS is a fast, training-free method for finding models that balance predictive accuracy and inference efficiency.
